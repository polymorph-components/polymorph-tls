# `experimental/`

Prototypes exploring designs around the `lann:tls` package. Nothing here
is a delivery: no stability, no security review, and no coverage by the
default gates (`just check` builds the workspace-member crates;
workspace-excluded crates and the smoke rigs build and run only on
demand). A prototype either graduates — moving out of this tree through
the normal review path — or is deleted; its README records what it
demonstrated either way.
